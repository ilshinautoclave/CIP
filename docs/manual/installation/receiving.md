# 3.1 반입 및 점검

Warm Isostatic Press를 수령하시는 **즉시 점검**해야 합니다.

::: warning 주의
운송 시 생긴 어떠한 손상도 **즉시** 알려주십시오.
만일 장비가 즉시 사용되지 않을 경우에는 기후나 온도 등에 의한 손상이 없도록 보호하십시오.
:::

## 수령 즉시 확인 사항

| No. | 확인 항목 | 확인 |
| --- | --- | --- |
| 1 | 외관 손상(찍힘, 변형, 도장 벗겨짐) 여부 | ☐ |
| 2 | 압력용기·커버 표면 손상 여부 | ☐ |
| 3 | 배관·피팅 연결부 이완 여부 | ☐ |
| 4 | 제어반 도어 및 내부 부품 고정 상태 | ☐ |
| 5 | 명판(Name plate)의 Model No. / Serial No. 일치 여부 | ☐ |
| 6 | 동봉 부속품 및 매뉴얼 수량 | ☐ |

## 운반 시 주의

- 가능하면 **지게차**를 사용하여 압력용기 부분을 들되, **무게 중심을 고려**하여 들 수 있도록 하십시오.
- 물을 포함한 무게를 참고하여 **기중기의 사양**을 확인하시기 바랍니다.
- 물의 무게를 포함한 총 무게를 견딜 수 있는 기반 위에 장비를 설치하시기 바랍니다.

## 설치 공간

유지보수를 위해 장비 주위에 **800 mm의 여유 공간**을 두시기 바랍니다.

::: tip NOTE
장비가 바로 사용되지 않는 경우, 결로와 부식을 막기 위해 방청 처리 후 실내 보관하십시오.
압력용기 내부에 잔류수가 있으면 반드시 배수 후 보관하십시오.
:::
