# 3.2 설치 장소 및 수평

본 장비를 설치 장소에 이동·설치한 후에는 장비의 레벨을 **수직·수평 방향 모두** 면밀히 확인하십시오.
특히 **압력용기 상부에서의 수평**을 확인하시기 바랍니다.

::: warning 주의
커버와 커버 리프팅 장치의 연결 후에 **커버와 압력용기 간의 공차 및 레벨**을 확인하십시오.
이때 커버의 상승·하강은 **최대한 천천히** 하십시오.
커버와 압력용기는 **어떤 마찰이나 충돌도 없어야 합니다.**
:::

## 수평 조정 절차

1. 장비를 최종 설치 위치로 이동합니다.
2. 장비 하부 레벨링 볼트로 **전후·좌우** 수평을 잡습니다.
3. **압력용기 상부 플랜지 면**에 수평계를 올려 수평을 확인합니다.
4. 커버를 **매우 천천히** 하강시키며 압력용기와의 간섭을 확인합니다.
5. 간섭이 있으면 압력용기 내경과 커버의 중심을 다시 맞춥니다.
6. 수평이 맞으면 레벨링 볼트를 고정합니다.

## 핀(Pin) 동작 확인

상기 작업이 끝나면 **PIN을 삽입/인출하여 확인**하시기 바랍니다.
이때에도 Pin과 압력용기 및 커버와의 **충돌이나 마찰이 없어야 합니다.**

| 확인 항목 | 정상 판정 |
| --- | --- |
| 커버 하강 | 마찰음 없이 정위치 안착, 하강 완료 센서 감지 |
| 핀 삽입 | 걸림 없이 삽입, Pin In 센서 감지 |
| 핀 인출 | 걸림 없이 인출, Pin Out 센서 감지 |
| 커버 상승 | 마찰 없이 상승, 상승 완료 센서 감지 |

::: tip
수평이 맞지 않으면 **커버 상승/하강 불량**과 **핀 고착**의 주된 원인이 됩니다.
증상이 나타나면 [자가 진단 › 커버 상승/하강 불량](/troubleshooting/cover-movement)을 참조하십시오.
:::
