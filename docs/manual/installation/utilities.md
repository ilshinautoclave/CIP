# 3.3 유틸리티 연결

## 공급 조건

| 유틸리티 | 사양 | 접속 |
| --- | --- | --- |
| Air | 0.6 ~ 0.9 MPa | 12 mm 우레탄 호스 (또는 1/2" PT) |
| 전원 | 220 VAC 또는 380 VAC (±10 %), 3-Phase | "C" type plug |
| 순수 (Pure Water) | 0.77 Liter | 수동 보충 |

::: warning 주의
전원 사양은 **호기별로 다릅니다.** 명판과 [데이터 시트](../intro/datasheet)를 반드시 확인한 후 결선하십시오.
:::

## 전기 연결

1. 메인 전원의 연결이 올바른지 확인하십시오.
2. 전선들의 단자대 연결 상태에 이상이 없는지, **Terminal의 조임 상태**를 확인하십시오.
3. 접지(Earth)가 확실히 연결되었는지 확인하십시오.

## 에어 연결

1. 에어 공급 라인의 연결 상태 및 에어 공급 상태를 확인하십시오.
2. 에어의 공급 압력은 **0.6 ~ 0.9 MPa**가 되어야 합니다.
3. 에어의 유량은 **가압 속도**를 결정합니다.
   - 공급 유량이 많으면 → 가압 속도가 빨라집니다.
   - 공급 유량이 적으면 → 가압 속도가 늦어집니다.
4. 가압 속도는 고객의 용도에 맞게 **V-1 (Air control valve)** 로 설정하십시오.

::: tip NOTE
가압 속도가 지나치게 빠르면 O-ring 손상과 몰드 파손의 원인이 됩니다.
초기 설정 시에는 **느린 쪽**에서 시작하여 공정에 맞게 조절하십시오.
:::

## 순수 공급

1. 순수 공급 탱크 내부에 공급수를 채우십시오. (**수동으로 채워야 합니다.**)
2. 초기에는 **90 % 이상** 채웁니다.
3. 베셀에 물이 채워지면 약 **60 %** 의 수위가 됩니다.

::: danger
반드시 **순수(Pure Water)** 를 사용하십시오. 수돗물·지하수 사용 시 스케일과 부식으로 펌프와 밸브가 손상됩니다.
:::
