# 부록 B. 용어집

## 장비 · 공정

| 용어 | 설명 |
| --- | --- |
| **W.I.P** | Warm Isostatic Press. 온간 등방압 가압 장치 |
| **C.I.P** | Cold Isostatic Press. 냉간(상온) 등방압 가압 장치 |
| **H.I.P** | Hot Isostatic Press. 열간 등방압 가압 장치 |
| **등방압 가압** | 시료에 모든 방향에서 균일한 압력을 가하는 성형 방식 |
| **압력 매체** | 압력을 전달하는 유체. 본 장비는 **순수(Pure Water)** 사용 |
| **몰드(Mold)** | 시료를 감싸 압력 매체로부터 격리하는 성형 용기 |
| **바스켓(Basket)** | 시료를 담아 베셀에 투입하는 용기 |

## 구성품

| 용어 | 설명 |
| --- | --- |
| **Pressure Vessel** | 압력용기. 시료를 가압하는 본체 |
| **Cover** | 압력용기 상부 밀폐 커버 |
| **Pin Closure** | 핀으로 커버를 고정하는 밀폐 방식 |
| **O-ring** | 커버와 압력용기 사이를 밀봉하는 링 |
| **Back-up Ring** | O-ring의 압출을 방지하는 보조 링 |
| **Rupture Disc** | 과압 시 파열되어 압력을 방출하는 안전 장치 (65,000 psi) |
| **Weep Hole** | 압력용기 이상 시 누설이 나타나는 확인 구멍 |
| **Air Driven Pump** | 공압으로 구동되는 증압 펌프 (압력비 1400:1) |
| **플런저 Seal** | 펌프 플런저를 밀봉하는 씰 |
| **Check Valve** | 역류 방지 밸브 |
| **Reservoir Tank** | 압력 매체 저장 탱크 |

## 밸브

| 용어 | 설명 |
| --- | --- |
| **Release Valve** | 감압 밸브. 0.1 MPa/sec로 서서히 개방 |
| **Air Vent Valve** | 베셀 내 잔류 공기 배출 밸브 (Shut off valve) |
| **Air Control Valve (V-1)** | 펌프 구동 에어 유량 조절 = 가압 속도 조절 |
| **Air Regulator** | 공급 에어 압력 조정기 |
| **Ball Valve** | 개폐용 볼 밸브 |
| **Needle Valve** | 미세 유량 조절 밸브 |

## 제어

| 용어 | 설명 |
| --- | --- |
| **PLC** | Programmable Logic Controller. 장비 제어 장치 |
| **HMI** | Human Machine Interface. 조작·표시 화면 |
| **PV** | Process Value. 현재값 |
| **SV** | Set Value. 설정값 |
| **High 값** | 가압 펌프가 정지되는 목표 압력 |
| **Low 값** | 가압 펌프가 재기동되는 재가압 압력 |
| **인터록(Interlock)** | 안전 조건이 충족되어야 다음 동작을 허용하는 제어 |
| **양수 버튼(Two-handed)** | 두 손으로 동시에 눌러야 동작하는 안전 스위치 |
| **E.M.O STOP** | Emergency Off. 비상 정지 |
| **STEP** | 압력·유지시간으로 구성된 가압 단계 |
| **패턴(Pattern)** | 여러 STEP을 묶어 저장한 운전 조건 |

## 단위

| 단위 | 환산 |
| --- | --- |
| 1 MPa | 10 bar |
| 1 MPa | 약 145 psi |
| 600 MPa | 6,000 bar ≈ 87,000 psi |
| 65,000 psi | 약 448 MPa ≈ 4,482 bar |
