아래 정보를 함께 알려주시면 훨씬 빠르게 조치할 수 있습니다.

| 항목 | 확인 위치 |
| --- | --- |
| **Model No.** | 장비 명판 / 매뉴얼 표지 |

| 설치 장소 | — |
| 증상 발생 시점 | 가압 중 / 감압 후 / 커버 조작 시 등 |
| 표시 압력·온도 | HMI 화면 |

::: tip
HMI 화면과 이상 부위를 **사진으로 찍어 보내주시면** 원인 파악이 크게 빨라집니다.
:::

## 장비 개조 승인

장비의 개선 및 수정이 필요할 경우 **반드시 폐사의 승인**을 받으시기 바랍니다.
무단 개조 시 보증이 소멸되며, 이후 발생하는 손상에 대해 책임지지 않습니다.
→ [2.4 책임의 한계](../safety/liability)
