# 4.4 3D 모델 보기

실험실용 CIP(WIP26021)의 설계 모델입니다. 드래그로 회전, 휠로 확대, 우클릭 드래그로 이동합니다.

- **커버 열기**: 핀 인출(Pin OUT, 300 mm) → 커버 상승(Cover UP, 500 mm) 순서로 움직입니다. **커버 닫기**는 커버 하강(Cover DOWN) → 핀 삽입(Pin IN) 순서입니다. ([5.4 시료 장착 및 투입](/manual/operation/loading)의 인터록 순서)
- **커버 투명**: 외장 커버를 반투명하게 해서 내부 구성품을 보여줍니다.
- 부품을 클릭하면 명칭과 도면 번호가 표시됩니다. 오른쪽 목록에서 조립체별로 숨기거나 보일 수 있습니다.

::: tip NOTE
3D 모델은 형상 이해를 돕기 위한 자료입니다. 실제 장비는 사양 타입(A형/B형)과 옵션에 따라 외관이 다를 수 있습니다.
:::
