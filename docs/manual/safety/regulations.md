# 2.2 안전 규정

설치, 운전 및 유지보수에 앞서 지급된 본 매뉴얼을 반드시 읽고 확인하십시오.
장치에 대한 지식 및 안전사항과 예방조치 등을 수행한 후 장치를 운전하십시오.

::: warning 주의
- 운전자는 작업–운전–안전 규정에 대해 반드시 주의를 하여야 합니다. 또한 내부 공장의 규정을 숙지해야 합니다.
- 유지보수와 수리는 **훈련된 요원 혹은 해당 작업에 대한 자격을 얻은 사람의 감독 아래** 수행되어야 합니다.
- 특정 공구 사용 및 훈련은 아래의 규칙에 따라야 하며, **훈련된 전문가만이** 유지보수와 수리를 해야 합니다.
:::

## 반드시 지켜야 할 사항

| No. | 내용 |
| --- | --- |
| 1 | 장비의 사용은 **훈련 받은 자**가 하여야 합니다. |
| 2 | **고압 장비**이므로 취급에 주의를 요합니다. |
| 3 | **Weep hole**로부터 손가락이나 손의 안전사고에 유의하십시오. |
| 4 | 파손되거나 문제 발생 소지가 있는 부분은 사용을 금지합니다. |
| 5 | 장비가 운전 중이거나 고압이 걸려 있을 때 **피팅류나 연결부를 절대 조이지 마십시오.** |
| 6 | 장비 구동부로부터 신체 접촉과 느슨한 옷으로 인한 안전사고에 유의하십시오. |
| 7 | 이물질이 튈 경우를 대비해 **보호안경**을 착용하십시오. |
| 8 | 지정된 온도 범위에서만 장비를 작동하십시오. (호기별 상이 — 아래 참조) |

## 운전 온도 범위 (사양 타입별)

| 타입 | 범위 |
| --- | --- |
| **A형** (히터 탑재) | 50 ˚F ~ 185 ˚F (10 ℃ ~ 85 ℃) |
| **B형** (히터 없음) | 50 ˚F ~ 140 ˚F (10 ℃ ~ 60 ℃) |

::: tip
보유 장비의 사양 타입은 **장비 명판**과 납품 데이터 시트에서 확인하십시오.
→ [부록 A. 사양 타입 비교](../appendix/model-comparison)
:::

::: danger 폭발 위험 환경
폭발 방지 옵션이 적용되지 않은 장비는 **폭발성 연무나 다른 가연성 조건을 포함하는 환경**에서 사용하지 마십시오.
:::

## 운전 중 절대 금지 사항

1. 압력이 남아 있는 상태에서 **핀(Pin) 인출** 조작
2. 압력이 남아 있는 상태에서 **피팅·연결부 조임**
3. Release valve를 **급격히 개방**하는 행위 (0.1 MPa/sec 준수)
4. 설정 압력 **600 MPa 초과** 운전
5. 바스켓 없이 시료를 베셀에 직접 투입
