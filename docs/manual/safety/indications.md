# 2.1 안전 표시

본 매뉴얼에서 사용하는 안전 표시의 의미는 다음과 같습니다. 매뉴얼 전체에 걸쳐 각 항목 시작 전에 표기되어 있습니다.

| 표시 | 의미 |
| --- | --- |
| <span class="safety-badge danger">위 험</span> | 사망 혹은 심각한 부상을 야기할 수 있는 잠재적인 위험을 표시합니다. |
| <span class="safety-badge warning">경 고</span> | 사망까지 갈 수 있거나 또는 심각한 부상을 야기할 수 있는 잠재적인 위험을 표시합니다. |
| <span class="safety-badge caution">주 의</span> | 최소한, 혹은 약간의 부상 및 기계적 손상을 야기할 수 있는 잠재적인 위험을 표시합니다. |
| **NOTE** | 참조 자료에 대한 정보를 표시합니다. |

## 웹 매뉴얼에서의 표기

이 웹 매뉴얼에서는 아래와 같은 색상 박스로 표시합니다.

::: danger 위험
사망 혹은 심각한 부상을 야기할 수 있는 항목입니다.
:::

::: warning 경고 / 주의
심각한 부상 또는 기계적 손상을 야기할 수 있는 항목입니다.
:::

::: tip NOTE
참조 정보 및 권장 사항입니다.
:::

::: info 정보
운전에 도움이 되는 부가 설명입니다.
:::
