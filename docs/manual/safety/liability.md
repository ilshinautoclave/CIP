# 2.4 책임의 한계

다음 사항에 대해서는 ㈜일신오토클레이브의 책임이 없음을 알립니다.

| 구분 | 내용 |
| --- | --- |
| a | 계약에 제시된 장비 사양과 다른 사양에 의해서 발생한 손상 |
| b | 매뉴얼에 기술되지 않은 작업 조건에 의한 손상 |
| c | 폐사에서 지정하거나 인정하지 않는 부적합한 부품들에 의해서 생기는 손상이나 문제 |
| d | 본 장비를 운용하면서 이루어지는 온도·압력에 의해 생산되는 몰드 제품의 결과 등에 대한 사항 |
| e | 폐사가 인정하는 작업이 아닌 다른 용도 및 공정에 의해 발생한 손상 |
| f | 자연재해에 의한 충격 및 손상 |

::: warning 주의
장비의 개선 및 수정이 필요할 경우 **반드시 폐사의 승인**을 받으시기 바랍니다.
무단 개조 시 보증이 소멸되며, 이후 발생하는 모든 손상에 대해 책임지지 않습니다.
:::

## 수출 규제 관련 고지

본 제품(부품, 기술자료 및 동작 정보)에 대한 설명은 **한국 또는 미국의 법률 및 규정의 규제**를 받으며 제작되었음을 본 매뉴얼을 통해 알립니다.
귀사(기관)에서는 법률 및 규정에 대한 정부의 승인이 필요할 수 있습니다.
