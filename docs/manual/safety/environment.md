# 2.3 작업 환경

## 설치 환경 요구 조건

| 항목 | 기준 | 비고 |
| --- | --- | --- |
| 주위 온도 | 10 ℃ ~ 50 ℃ | — |
| 상대 습도 | 30 % ~ 95 % | 결로 없을 것 |
| 조도 | 최소 300 Lx | 자체 조명 없음 |
| 소음 | 장비 소음 75 dB 이하 | 공장 소음 85 dB 이상 시 귀마개 필요 |
| 유지보수 공간 | 장비 주위 **800 mm** 이상 | 전 방향 |
| 바닥 | 물 무게를 포함한 총 중량을 견딜 것 | 수평 확보 필수 |

## 작업자 보호구

| 보호구 | 착용 시점 |
| --- | --- |
| 보호안경 | 운전 전 구간 (이물질 비산 대비) |
| 안전화 | 상시 |
| 귀마개 | 주변 소음 85 dB 이상인 경우 |
| 작업복 | 상시 — 느슨한 옷, 장신구 금지 |

::: warning 경고
장비 구동부(커버 리프팅 실린더, 핀 이동 실린더) 주변에서는 신체 접촉과 **느슨한 옷으로 인한 끼임 사고**에 유의하십시오.
:::

## 위험 구역

| 구역 | 위험 요인 | 조치 |
| --- | --- | --- |
| 압력용기 상부 | 커버 상승/하강 시 끼임 | 동작 중 접근 금지 |
| 핀 이동부 측면 | 핀 삽입/인출 시 끼임 | 동작 중 손 접근 금지 |
| Weep hole 주변 | 고압 분출 | 가압 중 접근 금지 |
| 고압 배관 | 파열 시 비산 | 가압 중 배관 접촉·조임 금지 |
