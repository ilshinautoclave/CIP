## 표시 항목

| No. | 항목 | 설명 |
| --- | --- | --- |
| ① | **패턴번호** | "STEP"에서 저장한 패턴 번호. "SET"에서 설정된 패턴 번호를 보여줍니다. |
| ② | **스텝번호** | "SET"에서 저장한 STEP에 대한 번호. 현재 진행 중인 STEP 번호를 보여줍니다. |
| ③ | **스텝압력** | "SET"에서 저장한 STEP에 대한 압력. 현재 STEP의 목표 압력을 보여줍니다. |
| ④ | **베셀온도** | 베셀의 현재 온도(좌) / 설정 온도(우). 베셀 내부의 물 온도를 알려줍니다. |
| ⑤ | **히터온도** | 히터의 현재 온도(좌) / 설정 온도(우). 실리콘 히터의 목표 온도를 설정하고 현재 온도를 보여줍니다. |
| ⑥ | **베셀압력** | 현재 상태의 베셀 압력 |
| ⑦ | **예열시간** | 예열 설정 및 유지 시간 |

## 조작 버튼

| No. | 버튼 | 기능 |
| --- | --- | --- |
| ⑧ | **가압 (ON / OFF)** | 펌프 작동에 대한 ON/OFF. 펌프를 작동하여 가압을 시작하거나 중단할 때 사용합니다. |
| ⑨ | **핀 (삽입 / 인출)** | 가압 시 커버가 압력에 의해 이탈되는 것을 방지합니다. 안전상의 문제로 **커버가 삽입된 후 핀이 삽입되어 있어야만** 가압 펌프가 작동합니다. |
| ⑩ | **커버 (상승 / 하강)** | 샘플 투입 및 회수와 더불어 가압을 위해 반드시 닫아야만 하는 부품입니다. |
| ⑪ | **히터 (ON / OFF)** | 베셀의 온도를 올려주기 위해 필요한 장치입니다. |

## 하단 탭

| 탭 | 내용 |
| --- | --- |
| **AUTO** | 메인(자동 운전) 화면 |
| **SET** | 알람 및 기본 구동 설정 → [6.2 알람 및 구동 설정](./alarm-setting) |
| **STEP** | 압력·유지시간 패턴 설정 → [6.3 STEP 패턴 설정](./step-pattern) |
| **GRAPH** | 온도·압력 추이 그래프 |
| **ALARM** | 알람 이력 확인 → [알람 코드표](/technical/alarm-code-table) |

::: warning 인터록
**커버 하강 → 핀 삽입**이 모두 완료되어야 **가압 ON** 버튼이 동작합니다.
순서를 건너뛸 수 없으며, 램프가 점등되지 않으면 펌프는 기동하지 않습니다.
:::
