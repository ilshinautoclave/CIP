## 알람 설정

| No. | 항목 | 설명 |
| --- | --- | --- |
| ① | **베셀 상한 압력 설정** | 설정된 압력 이상으로 설비가 구동될 경우 알람이 발생합니다. |
| ② | **베셀 상한 온도 설정** | 설정된 온도 이상으로 설비가 구동될 경우 알람이 발생합니다. 메인 화면에서 설정된 온도 이상으로 감지될 경우 알람이 발생됩니다. |
| ③ | **히터 상한 온도 설정** | 설정된 온도 이상으로 설비가 구동될 경우 알람이 발생합니다. |

::: danger
베셀 상한 압력은 **6,000 bar (600 MPa)를 초과하여 설정하지 마십시오.**
:::

## 구동 설정

| No. | 항목 | 설명 |
| --- | --- | --- |
| ④ | **재가압 압력 설정** | 설정된 압력을 유지하는 과정에서 해당 설정값보다 떨어질 경우 **보상 가압**이 이루어집니다. |
| ⑤ | **커버 열림 및 닫힘 사용 압력** | 설정된 압력보다 **낮은 압력에서만** 커버가 작동됩니다. |
| ⑥ | **그래프 저장 주기** | 설정된 시간마다 주기적인 온도/압력의 변화를 측정·저장합니다. |
| — | **압력 BIAS / 영점조정** | 무압 상태에서 압력 표시값의 영점을 보정합니다. |
| ⑦ | **부저 동작 시간** | 알람이 울릴 경우 지속되는 시간입니다. |

## 권장 설정값

| 항목 | 권장값 | 비고 |
| --- | --- | --- |
| 베셀 상한 압력 | 목표 압력 + 100 ~ 200 bar | 최대 6,000 bar |
| 베셀 상한 온도 | 85 ℃ 이하 | 최대 운전 조건 |
| 히터 상한 온도 | 공정 온도 + 10 ℃ | — |
| 재가압 압력 | 목표 압력 − 50 ~ 100 bar | 너무 좁으면 펌프가 빈번히 기동 |
| 커버 사용 압력 | 0 ~ 5 bar | 안전상 낮게 설정 |
| 그래프 저장 주기 | 1 ~ 10 sec | 길면 데이터가 성깁니다 |
| 부저 동작 시간 | 10 ~ 30 sec | — |

## 영점 조정 (압력 BIAS)

1. 베셀을 **완전히 감압**하고 **커버를 개방**합니다.
2. SET 화면의 **영점조정** 버튼을 누릅니다.
3. 베셀압력 표시가 **0 bar**가 되는지 확인합니다.

::: warning
압력이 남아 있는 상태에서 영점 조정을 하면 **실제 압력보다 낮게 표시**되어 매우 위험합니다.
반드시 무압·커버 개방 상태에서 수행하십시오.
:::
