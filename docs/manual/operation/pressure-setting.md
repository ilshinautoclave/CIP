# 5.3 압력 설정

압력 설정은 **Pressure Low 값**과 **Pressure High 값** 2개를 설정합니다.

| 설정값 | 의미 |
| --- | --- |
| **Low 값** | 가압 펌프가 **기동**되는 값 (재가압 압력) |
| **High 값** | 가압 펌프가 **정지**되는 값 (목표 압력) |

::: danger 주의
가압 압력의 설정값은 **600 MPa (6,000 bar)를 초과하여서는 안 됩니다.**
:::

## 터치 HMI 방식 (A형)

1. 하단의 **STEP** 버튼을 눌러 STEP 화면으로 이동합니다.
2. 각 STEP에 해당하는 **압력**과 **유지 시간(초)** 을 입력합니다.
3. 필요 시 **예열 시간**을 입력합니다.
4. **저장하기**를 눌러 패턴(1~10)에 저장합니다.
5. 알람 설정(상한 압력·온도)과 재가압 압력은 **SET** 화면에서 설정합니다.

자세한 화면 설명은 [6.3 STEP 패턴 설정](../hmi/step-pattern)을 참조하십시오.

## 버튼/지시계 방식 (B형)

1. **MOD**를 눌러 **HI LED**가 점등되도록 하십시오. → High Data 설정 모드입니다.
2. **▶** 또는 **▲** 를 사용해 설정 압력을 입력하고 **ENT**를 눌러 입력을 완료합니다.
3. **MOD**를 눌러 **LOW LED**가 점등되도록 하십시오. → Low Data 설정 모드입니다.
4. **▶** 또는 **▲** 를 사용해 설정 압력을 입력하고 **ENT**를 눌러 입력을 완료합니다.
5. **영점 조정(Calibration)** 을 합니다.
   - 압력이 제거된 상태에서 **(ENT + ▶)** 를 눌러 줍니다.
   - 즉, **커버가 OPEN 된 상태**에서 영점 조정을 합니다.

::: tip NOTE
기타 자세한 조작 방법은 해당 호기에 적용된 **압력 지시계 취급설명서**를 참조하십시오.
:::

## 설정 예시

| 항목 | 예시값 | 설명 |
| --- | --- | --- |
| High (목표 압력) | 5,000 bar | 이 값에 도달하면 펌프 정지, 부저 동작 |
| Low (재가압 압력) | 4,900 bar | 이 값 아래로 떨어지면 재가압 |
| 유지 시간 | 300 sec | 목표 압력 유지 시간 |
| 상한 압력 알람 | 6,000 bar | 초과 시 알람 발생 |
