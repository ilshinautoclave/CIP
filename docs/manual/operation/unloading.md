# 5.7 시료 반출

::: danger 반드시 먼저 확인
- 압력이 완전히 **Zero**가 되었는지 확인합니다.
- 압력이 완전히 제거되지 않은 상태에서의 **안전핀 동작을 하지 마십시오.**
- 이는 안전사고와 장비 손상의 원인이 됩니다.
:::

## 1) 핀 인출 (Pin OUT)

1. **핀 인출 버튼을 지속적으로 누르면** 실린더에 에어가 공급되어 PIN이 인출됩니다.
2. 인출이 완료되어 센서에 감지되면 **자동으로 에어가 차단**됩니다.
3. 컨트롤 패널의 **Pin Out Lamp**가 점등됩니다.

::: warning
핀이 원활히 인출되지 않으면 무리하게 조작하지 마십시오.
[자가 진단 › 핀이 빠지지 않음](/troubleshooting/pin-stuck)의 절차를 따르십시오.
:::

## 2) 커버 상승 (Cover UP)

1. 커버를 **완전히** 상승시켜 정위치에 장착합니다.
2. 조작 방법 (사양 타입별)
   - **A형 (터치 HMI)**: 화면의 **커버 › 상승** 버튼을 누릅니다.
   - **B형 (버튼/스위치)**: **Cover-1, Cover-2 스위치를 동시에** 조작합니다. (양수 버튼)
3. 상승이 완료되어 센서에 감지되면 **자동으로 에어가 차단**됩니다.
4. 컨트롤 패널의 **Cover Up Lamp**가 점등됩니다.

## 3) 시료 반출

1. **바스켓을 분리**하여 투입한 시료를 반출합니다.
2. 시료 반출 시 **Vessel 내면에 스크래치가 발생되지 않도록** 주의하여 주시기 바랍니다.

::: warning 주의
Vessel 내면의 스크래치는 **O-ring 손상과 누수의 직접적인 원인**이 됩니다.
바스켓과 시료를 수직으로 들어 올려 반출하십시오.
:::

## 운전 종료 후 점검

| 항목 | 내용 |
| --- | --- |
| Vessel 내부 | 이물질·잔류 몰드 파편 제거 |
| O-ring | 부풀음·변형·손상 여부 육안 확인 |
| Water Tank | 수위 확인 (다음 운전 전 보충) |
| 배관·피팅 | 누수 흔적 확인 |
| Release / Air vent valve | 다음 운전을 위해 상태 확인 |

전체 운전 순서를 다시 보려면 → [5.1 운전 전 점검](./pre-check)
