# 5.4 시료 장착 및 투입

## 1) 바스켓에 시료 투입

- **몰드화 되어 있는 시료**를 준비합니다.
- 시료를 **바스켓 내부에** 투입합니다.

::: danger 바스켓 필수
바스켓에 시료를 넣지 않고 Vessel 내에 **직접 넣을 경우**, 감압 시 물의 흐름에 의해 **몰드가 터지거나 배관으로 투입되어 막힐 수 있습니다.**
:::

::: tip NOTE
- Cover 및 Pin의 움직임은 **Air Cylinder**에 의해 이루어집니다.
- 각 실린더 끝단에는 제어 및 위치를 감지하기 위해 **센서**가 장착되어 있습니다.
- 이 센서는 서로 **연동(Interlock)** 되어 Cover 및 Pin이 제어됩니다.
:::

## 2) 커버 하강 (Cover DOWN)

1. 커버를 내려 정위치에 장착합니다.
2. 조작 방법 (사양 타입별)
   - **A형 (터치 HMI)**: 화면의 **커버 › 하강** 버튼을 누릅니다.
   - **B형 (버튼/스위치)**: **Cover-1, Cover-2 스위치를 동시에** 조작합니다. (양수 버튼)
3. 하강이 완료되어 센서에 감지되면 **자동으로 에어가 차단**됩니다.
4. 컨트롤 패널의 **커버 하강 램프(Cover Down Lamp)** 가 점등됩니다.

::: warning 안전
안전을 위하여 **PIN이 인출된 경우에는 가압이 되지 않습니다.**
:::

## 3) 핀 삽입 (Pin IN)

1. 핀을 삽입합니다.
2. **커버가 완전히 하강하여 실린더 측면의 센서를 감지해야만** 핀 동작을 할 수 있습니다.
3. 핀 삽입 버튼을 작동하면 실린더에 에어가 공급되어 핀이 삽입됩니다.
4. 삽입이 완료되어 센서에 감지되면 **자동으로 에어가 차단**됩니다.
5. 컨트롤 패널의 **Pin In Lamp**가 점등됩니다.

## 인터록 요약

```
커버 하강 완료 (센서 감지)
        ↓
    핀 삽입 가능
        ↓
핀 삽입 완료 (센서 감지)
        ↓
    가압 펌프 동작 가능
```

::: warning
**커버 하강 램프**와 **핀 삽입 램프**가 모두 점등되지 않으면 가압 펌프가 작동하지 않습니다.
램프가 점등되지 않으면 [자가 진단 › 승압/유지 불량](/troubleshooting/pressure-build)을 참조하십시오.
:::
