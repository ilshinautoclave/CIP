# 5.6 감압 (Release)

목표 시간 동안 가압이 유지된 후, 운전을 정지합니다.

## 1) 가압 펌프 OFF 확인

- 가압 Pump가 **OFF**로 전환되었는지 확인합니다.
- 가압 Pump가 OFF로 전환되면 **에어가 차단**됩니다.
- 컨트롤 패널의 **Pump OFF Lamp**가 점등됩니다.

## 2) Release Valve 개방

::: danger 매우 서서히 개방
Release valve를 **매우 서서히** 열어 주십시오.

- 감압 속도: **0.1 MPa/sec**
- 빨리 열면 **충격에 의해 배관이 파열되어 사용자의 상해를 초래**할 수 있습니다.
- Vessel 내의 시료가 감압 속도에 의해 **몰드가 손상**될 수 있습니다.
:::

### 감압 속도 기준

| 목표 압력 | 0.1 MPa/sec 기준 소요 시간 |
| --- | --- |
| 600 MPa (6,000 bar) | 약 100 분 |
| 400 MPa (4,000 bar) | 약 67 분 |
| 200 MPa (2,000 bar) | 약 33 분 |

::: tip
감압 속도는 공정 조건과 몰드 재질에 따라 조정될 수 있으나, **0.1 MPa/sec를 초과하지 않는 것**을 원칙으로 합니다.
:::

## 3) 압력 확인

압력계와 HMI 표시 압력이 모두 **0 (Zero)** 인지 확인합니다.

::: danger
압력이 완전히 제거되지 않은 상태에서 **안전핀을 조작하지 마십시오.**
이는 **안전사고와 장비 손상의 원인**이 됩니다.
:::
