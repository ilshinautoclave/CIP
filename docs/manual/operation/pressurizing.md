# 5.5 가압 (Pumping)

::: danger 주의
가압 압력의 설정값은 **600 MPa (6,000 bar)을 초과하여서는 안 됩니다.**
:::

## 1) 펌프 동작

1. **커버 하강, 핀 삽입**이 점등되지 않으면 가압 펌프가 작동하지 않습니다.
2. 가압 전 [5.1 운전 전 점검](./pre-check)의 **8) 항 모든 밸브가 열려 있는지** 재확인합니다.
3. **가압 ON** 버튼을 눌러주면 펌프로 에어가 공급되어 동작합니다.
4. 컨트롤 패널의 **가압 ON 버튼(Pump On Lamp)** 이 점등됩니다.

## 2) 에어 빼기 및 가압

용기 내부에 **잔류 에어를 완전히 제거**해야 합니다.

::: warning
만일 잔류 에어가 있으면 **O-ring 손상 및 가압 불량**의 원인이 됩니다.
:::

### A형 (터치 HMI)

1. 펌프가 가동하기 시작한 후 **약 5초 이후**, 설비 전면부의 **Release valve를 잠가** 줍니다.
2. 수초 ~ 수십 초 후부터 압력이 상승하기 시작합니다.
3. 설정한 **High 값**까지 가압됩니다.
4. 설정된 압력에 도달되면 **Pumping 동작이 정지되며 부저가 울립니다.**

### B형 (버튼/지시계)

1. **Release valve**를 먼저 잠가 줍니다.
2. 전면 Panel에 부착된 **FLUID INDICATOR**로 에어가 모두 빠져나가고 **물이 흐르는 것을 확인**합니다.
3. **Air vent valve (Shut off valve)** 를 완전히 잠급니다.
4. 수초 ~ 수십 초 후부터 압력이 상승하기 시작합니다.
5. 설정한 **High 값**까지 가압되며, **High Alarm이 점등되면 Pumping 동작이 정지**됩니다.

## 가압 속도 조절

- 가압 속도는 **V-1 (Air control valve)** 을 이용하여 에어 유량을 조절합니다.
- 에어량이 많아서 Pumping 속도가 빠르면 압력 상승도 빨라지므로, 가급적 **적절한 에어량을 조절하여 천천히 가압**하도록 합니다.

## 재가압 (보상 가압)

만일 시료의 수축으로 Vessel의 내부 압력이 감소하면, **Pressure Indicator의 Low 설정값에 도달 시 재 Pumping** 합니다.

```
목표 압력(High) 도달 → 펌프 정지
        ↓
시료 수축으로 압력 하강
        ↓
Low 설정값 도달 → 펌프 재기동
        ↓
High 값 도달 → 펌프 정지  (유지 시간 동안 반복)
```

::: tip
재가압 압력(Low)은 HMI의 **SET 화면 › 재가압 압력 설정**에서 변경할 수 있습니다.
:::
