# 5.2 전원 인가

## 절차

1. **Main plug**가 연결되어 있는지 확인합니다.
2. 전면 Control panel에서 전원을 **ON** 합니다.
   - 키 스위치 방식: Key를 돌려 **"ON"** 으로 향하게 놓습니다.
   - 버튼 방식: 전원 버튼을 **ON** 합니다.
3. HMI 또는 지시계에 화면이 정상적으로 표시되는지 확인합니다.

## 전원 인가 후 확인

| 확인 항목 | 정상 상태 |
| --- | --- |
| HMI 화면 | 메인 화면 정상 표시 |
| 베셀 압력 표시 | 0 bar 부근 (영점 확인) |
| 알람 표시 | 알람 없음 |
| E.M.O STOP | 해제(복귀) 상태 |
| 커버/핀 램프 | 현재 물리적 위치와 일치 |

::: warning 영점 확인
전원 인가 후 표시 압력이 0이 아니면 **영점 조정(Calibration)** 이 필요합니다.
커버가 열린 무압 상태에서 영점 조정을 수행하십시오. 자세한 절차는 [5.3 압력 설정](./pressure-setting)을 참조하십시오.
:::
