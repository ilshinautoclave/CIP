# 7.2 소모품 교체

::: info 보완 필요
정확한 **부품 번호(P/N)와 규격**은 납품 시 제공된 **Parts List**를 기준으로 채워 주십시오.
:::

| 소모품 | 위치 | 교체 시점 | 자가 교체 |
| --- | --- | --- | --- |
| **O-ring** | 압력용기 커버 | 부풀음·변형·경화·누수 시 | ✅ |

## O-ring 교체

::: danger
반드시 **압력 0 (Zero)**, **전원 차단**, **에어 차단** 상태에서 작업하십시오.
:::

1. 커버를 상승시키고 에어를 차단합니다.
2. 기존 O-ring과 Back-up Ring을 **비금속 공구**로 제거합니다.
3. 홈(Groove)과 접촉면을 깨끗이 닦고 스크래치가 없는지 확인합니다.
4. 새 O-ring에 **전용 윤활제**를 얇게 도포합니다.
5. 비틀리지 않게 장착합니다.
6. 커버를 천천히 하강시켜 간섭이 없는지 확인합니다.
7. 낮은 압력으로 시험 가압하여 누수를 확인합니다.

::: warning
- 금속 공구로 홈을 긁지 마십시오. 스크래치는 재누수의 원인이 됩니다.
- O-ring과 Back-up Ring은 **함께 교체**하는 것을 권장합니다.
:::

## Rupture Disc 교체

::: danger 규격 준수
반드시 **65,000 psi 규격**으로 교체하십시오.
규격이 다르면 과압 보호가 작동하지 않아 **압력용기 파열**로 이어질 수 있습니다.
:::

1. 압력을 완전히 감압합니다.
2. Rupture disc 홀더를 분해합니다.
3. 파열된 디스크를 제거하고 접촉면을 청소합니다.
4. 새 디스크를 **방향에 맞게** 장착합니다.
5. 규정 토크로 조립합니다.
6. 시험 가압하여 누수를 확인합니다.

## 압력 매체(순수) 교체

| 항목 | 기준 |
| --- | --- |
| 교체 주기 | 6개월 또는 오염 시 |
