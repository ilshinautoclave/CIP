# 7.1 점검 항목과 주기

::: info 보완 필요
아래 주기는 일반적인 고압 장비 기준의 **권장안**입니다.
귀사의 운전 빈도와 공정 조건에 맞추어 조정하고, 확정된 내용으로 갱신해 주십시오.
:::

## 일상 점검 (운전 전·후 매회)

| 항목 | 점검 내용 | 기준 |
| --- | --- | --- |
| Water Tank 수위 | 육안 | 운전 중 약 60 % |
| 에어 공급 압력 | 게이지 | 0.6 ~ 0.9 MPa |
| 누수 흔적 | 육안 | 물기 없음 |
| Vessel 내부 | 육안 | 이물질·몰드 파편 없음 |
| O-ring | 육안 | 부풀음·변형·손상 없음 |
| 커버·핀 동작 | 램프 점등 | 정상 감지 |
| E.M.O STOP | 육안 | 복귀 상태 |

## 주간 점검

| 항목 | 점검 내용 |
| --- | --- |
| Filter Ass'y | 오염도 확인 |
| 배관·피팅 | 이완 여부 (무압 상태에서) |
| 압력 게이지 ↔ HMI 표시 | 값 일치 여부 |
| 제어반 내부 | 먼지·이물 |

## 월간 점검

| 항목 | 점검 내용 |
| --- | --- |
| 압력 영점 | 무압·커버 개방 상태에서 영점 확인 |
| 센서·리미트 스위치 | 감지 위치 정확도 |
| Air Regulator | 설정 압력 유지 |
| 실린더 | 누기 여부 |
| Water Tank 내부 | 침전물·오염 |

## 6개월 점검

| 항목 | 점검 내용 |
| --- | --- |
| O-ring | 상태에 따라 교체 |
| Filter 카트리지 | 교체 |
| 압력 매체(순수) | 전량 교체 |
| 단자대 조임 | 재조임 |
| 접지 저항 | 측정 |

## 연간 점검 / 안전 진단

| 항목 | 점검 내용 | 담당 |
| --- | --- | --- |
| 압력용기 외관·비파괴 검사 | 균열·부식 | 전문 기관 |
| Rupture disc | 상태 확인 및 교체 검토 | 제조사 |
| 가압펌프 플런저 seal | 상태 확인 | 제조사 |
| Check valve | 동작 확인 | 제조사 |
| 안전 인터록 전수 시험 | 커버·핀 인터록 | 제조사 |
| 압력 시험 | 규정에 따름 | 전문 기관 |

::: warning
연간 안전 진단은 **제조사 또는 지정 전문업체**를 통해 수행하십시오. → [문의 및 A/S](../appendix/support)
:::
