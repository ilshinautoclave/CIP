# 1.6 일반 사항

::: danger
- 장비 조작, 운전, 작동, 유지보수, 고장 수리 시 엄격한 안전조치를 취하지 않을 경우 당사는 책임지지 않습니다.
- 운용자에 의해 임의로 작성된 문서는 인정하지 않으며, 본 문서로 운전 교육의 경고/주의 조치를 할 것을 권고합니다.
- 그렇지 않을 경우 당사는 본 설비에 대해서 어떤 책임도 지지 않습니다.
:::

## 1.6.2 조명

본 장비는 공장 규정에 의해 설계되었으며, **자체 조명 설비가 되어 있지 않습니다.**

| 항목 | 기준 |
| --- | --- |
| 주위 조도 | 최소 300 Lx |
| 배제해야 할 환경 | 깜박거림, 눈부심, 그림자, 고속 회전체 |

## 1.6.4 소음도

Warm Isostatic Press의 지속적인 소음은 **75 dB를 넘지 않습니다.**

::: warning 경고
공장의 소음이 **85 dB 이상**이면 운전자에게 경고 조치를 해야 하며, 귀마개 제공 등 적절한 대책을 강구해야 합니다.
:::
