# 1.2 데이터 시트

데이터 시트는 **납품 호기별로 다릅니다.** 아래는 대표 사양이며, 실제 장비의 Model No. / Serial No.와 데이터 시트는 **장비 명판** 및 납품 시 제공된 매뉴얼 표지를 확인하십시오.

## ISA-W70-6000 (대표)

| 항목 | 내용 |
| --- | --- |
| Model No. | ISA-W70-6000 |
| Max. Working Condition | 600 MPa @ 85 ℃ |
| Pure Water | 0.77 Liter |
| Air | 0.6 ~ 0.9 MPa |
| Electricity | 사양 타입별 상이 (아래 표 참조) |

## 사양 타입

동일 모델명이라도 **제어 방식과 전원 사양**이 다릅니다. 본 매뉴얼은 아래 두 타입을 기준으로 설명합니다.

| 구분 | **A형** | **B형** |
| --- | --- | --- |
| 제어 방식 | 터치 HMI | 버튼/스위치 + 지시계 |
| 히터 | 탑재 | 없음 |
| 전원 (예) | 220 VAC, 3-phase, 8 kW | 380 VAC, 3-phase, 3 kW |
| Water Tank 재질 (예) | SUS630 | SUS304 |
| Water Tank 치수 (예) | 70 mm(I.D) × 250 mm(I.L) | 70 mm(I.D) × 200 mm(I.L) |

::: warning 주의
전원 사양과 제어 방식은 호기마다 다릅니다.
운전 및 A/S 문의 전에 반드시 **장비 명판의 Model No. / Serial No.** 를 확인하십시오.
:::

두 타입의 상세 차이는 [부록 A. 사양 타입 비교](../appendix/model-comparison)에서 확인할 수 있습니다.
