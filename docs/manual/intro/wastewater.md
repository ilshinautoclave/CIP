# 1.5 폐수 처리

폐수의 소유주는 폐수 및 폐오일 처리에 대한 책임을 지며, 환경 보호와 관련된 법률에 대해 인지하고 있어야 합니다.

::: warning CAUTION
해당 설비는 자연환경으로 폐수를 누출하지 않습니다.
- 가정 쓰레기와 함께 배출하지 마십시오.
- 무허가 장소에서 태우지 마십시오.
:::

## 배출 대상

| 항목 | 처리 방법 |
| --- | --- |
| 압력 매체(순수, Pure Water) | 오염도 확인 후 사업장 폐수 처리 기준에 따라 배출 |
| 필터 카트리지 | 교체 후 지정 폐기물로 처리 |
| 씰·O-ring 등 소모품 | 지정 폐기물로 처리 |

## 배수 절차

1. 압력이 완전히 **0 (Zero)** 인지 확인합니다.
2. Reservoir Tank 하단의 Ball valve를 열어 Drain 포트로 배출합니다.
3. 배출된 폐수는 사업장 규정에 따른 용기에 수집합니다.
4. 배수 후 Ball valve를 닫고, 재운전 전 순수를 다시 보충합니다.
