## 파일 등록 방법

1. `docs/public/files/` 폴더를 만들고 파일을 넣습니다.
2. 이 페이지의 링크를 아래 형식으로 연결합니다.

```md
[다운로드](/CIP/files/manual-isa-w70-6000.pdf)
```

::: tip 대용량 파일
도면·카탈로그처럼 용량이 큰 파일은 저장소에 직접 넣기보다,
레인보우로보틱스 사이트처럼 **SharePoint·Google Drive 등 클라우드 공유 링크**를 거는 방식을 권장합니다.
그 경우 `config.mts`의 `nav`에서 다운로드 메뉴를 외부 링크로 바꾸면 됩니다.
:::
