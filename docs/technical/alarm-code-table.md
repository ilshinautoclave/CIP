# 알람 코드표

::: warning 작성 예정
알람 코드와 명칭은 **PLC 프로그램을 기준으로 확정**해야 합니다.
아래는 HMI 설정 항목과 인터록 구조에서 유추한 **초안**이며, 실제 코드로 교체해 주십시오.
:::

## 압력 관련

| 코드 | 알람명 | 발생 조건 | 조치 |
| --- | --- | --- | --- |
| (미정) | 베셀 상한 압력 | 설정된 상한 압력 초과 | 가압 OFF → 서서히 감압 → 설정값 확인 |
| (미정) | 압력 미상승 | 일정 시간 내 승압 실패 | [승압·유지 불량](/troubleshooting/pressure-build) |
| (미정) | 압력 센서 이상 | PT 신호 단선·범위 초과 | 배선 점검 → A/S 문의 |

## 온도 관련

| 코드 | 알람명 | 발생 조건 | 조치 |
| --- | --- | --- | --- |
| (미정) | 베셀 상한 온도 | 설정된 베셀 상한 온도 초과 | 히터 OFF → 자연 냉각 |
| (미정) | 히터 상한 온도 | 설정된 히터 상한 온도 초과 | 히터 OFF → 센서 점검 |
| (미정) | 온도 센서 이상 | 센서 신호 단선 | 배선 점검 → A/S 문의 |

## 인터록 관련

| 코드 | 알람명 | 발생 조건 | 조치 |
| --- | --- | --- | --- |
| (미정) | 커버 미하강 | 커버 하강 센서 미감지 상태에서 가압 시도 | 커버 재하강 → 센서 확인 |
| (미정) | 핀 미삽입 | 핀 삽입 센서 미감지 상태에서 가압 시도 | 핀 재삽입 → 리미트 확인 |
| (미정) | 커버 동작 금지 | 설정 압력 이상에서 커버 조작 시도 | 감압 후 재시도 |

## 유틸리티 관련

| 코드 | 알람명 | 발생 조건 | 조치 |
| --- | --- | --- | --- |
| (미정) | 에어 압력 저하 | 공급 에어 0.6 MPa 미만 | 에어 공급 확인 |
| (미정) | 수위 부족 | Water Tank 저수위 | 순수 보충 |
| (미정) | 비상 정지 | E.M.O STOP 동작 | 원인 제거 후 복귀 |

## 알람 대응 기본 순서

1. 가압 ON 상태이면 **가압 OFF**
2. HMI **ALARM** 탭에서 알람 내용 확인
3. 위 표에 따라 조치
4. 원인 제거 후 알람 리셋
5. 재발 시 **운전 중단 → A/S 문의**

상세 대응 절차 → [자가 진단 › 알람 발생 시 조치](/troubleshooting/alarm-response)

::: info 이 표를 완성하려면
- PLC 프로그램의 알람 비트 목록
- HMI 알람 화면에 실제 표시되는 문구
- 호기별 알람 차이 (히터 유무 등)

위 자료를 확보하면 정확한 코드표로 교체할 수 있습니다.
:::
