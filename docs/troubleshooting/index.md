# 자가 진단 가이드

장비에 이상이 발생했을 때, **A/S를 요청하기 전에** 아래 순서로 스스로 점검할 수 있도록 구성한 가이드입니다.

::: danger 점검 전 반드시
모든 점검은 **압력이 완전히 0(Zero)인 상태**에서 시작합니다.
압력이 남아 있는 상태에서 피팅류를 조이거나 핀을 조작하면 **중대한 인명사고**로 이어집니다.
:::

## 사용 방법

1. 아래 **증상별 빠른 찾기**에서 현재 증상을 고릅니다.
2. 해당 페이지의 **플로차트**를 위에서부터 따라갑니다.
3. 각 판정 단계의 **YES / NO**에 따라 조치를 수행합니다.
4. 조치 후에도 해결되지 않으면 페이지 하단의 **A/S 요청 정보**를 준비하여 연락 주십시오.

## 증상별 빠른 찾기

| 증상 | 진단 페이지 |
| --- | --- |
| 베셀 커버가 상승/하강이 원활하지 않다 | [커버 상승/하강 불량](./cover-movement) |
| 핀(Pin)이 빠지지 않는다 | [핀이 빠지지 않음](./pin-stuck) |
| 베셀이 마지막에 닫히지 않는다 | [베셀이 닫히지 않음](./vessel-closing) |
| 압력이 올라가지 않는다 / 유지되지 않는다 | [승압·유지 불량](./pressure-build) |
| 고압 배관·피팅에서 물이 샌다 | [고압 누수(Leak)](./leak) |
| 베셀·히터 온도가 이상하다 | [히터 온도 이상](./heater) |
| 알람이 발생했다 | [알람 발생 시 조치](./alarm-response) |

전체 증상 목록은 [증상별 빠른 찾기](./symptom-index)에서 확인할 수 있습니다.

::: warning
