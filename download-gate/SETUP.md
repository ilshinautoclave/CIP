# 자료 다운로드 고객정보 수집 설정 가이드

사이트 [다운로드](https://ilshinautoclave.github.io/CIP/download/) 페이지의 버튼을 누르면 고객정보 입력 폼이 뜹니다.
입력한 정보는 **구글 시트**에 쌓이고, 그다음 파일이 내려받아집니다.
한 번 입력한 방문자는 같은 브라우저에서 다시 입력하지 않아도 됩니다.

```
[다운로드 버튼] → [입력 폼] → [Apps Script 웹 앱] → 구글 시트에 기록
                                        ├→ 파일 등록됨: 구글 드라이브 링크로 다운로드
                                        └→ 파일 미등록: "자료 요청 접수" 안내 + 담당자 메일 알림
```

| 파일 | 역할 |
|---|---|
| `download-gate/Code.gs` | 구글 시트에 붙이는 서버 코드 (사이트에는 배포되지 않음) |
| `docs/public/download-gate.js` | 입력 폼 스크립트 (사이트에 배포됨) |
| `docs/.vitepress/config.mts` | 맨 위 `DOWNLOAD_GATE.endpoint`에 웹 앱 URL 입력 |
| `docs/download/index.md` | 다운로드 버튼 (`data-gate-file` = 시트의 파일키) |

`endpoint`가 비어 있는 동안에는 버튼을 누르면 "준비 중" 안내만 뜹니다.

---

## 1. 구글 시트 만들기 (한 번만)

1. 회사 구글 계정으로 [sheets.new](https://sheets.new)에서 새 시트를 만들고, 이름을 `CIP 자료 다운로드 고객 DB` 정도로 정합니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 붙여 넣은 뒤 저장합니다.
4. 맨 위 `CONFIG.NOTIFY_EMAIL`에 **알림 받을 메일 주소**를 넣습니다. 여러 명이면 쉼표로 구분합니다.
   - 새 고객이 등록될 때와, 아직 파일이 없는 자료를 요청받았을 때 메일이 옵니다.
   - 파일이 없는 자료를 요청한 고객에게는 "담당자가 이메일로 보내드립니다"라고 안내되므로, **반드시 설정**해 주세요.
5. 함수 선택 칸에서 `setup`을 고르고 **실행**을 누릅니다.
   - 권한 승인 창이 뜨면 계정을 고른 뒤 "고급 → (안전하지 않음)으로 이동 → 허용"을 누릅니다. 직접 만든 스크립트라 이런 경고가 뜹니다.
   - 실행이 끝나면 `리드`, `다운로드기록`, `파일목록` 탭이 생깁니다. `파일목록`에는 사이트의 자료 13개가 미리 들어가 있습니다.

## 2. 웹 앱으로 배포 (한 번만)

1. Apps Script 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형은 **웹 앱**을 고릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
3. 배포 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
4. `docs/.vitepress/config.mts` 맨 위의 `endpoint: ''` 따옴표 안에 붙여 넣고 커밋·푸시합니다.

> `Code.gs`를 나중에 수정하면 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**로 올려야 반영됩니다. URL은 그대로 유지됩니다.

## 3. 파일 등록 (자료가 생길 때마다)

1. 구글 드라이브에 폴더를 만들고 PDF/XLSX를 올립니다.
2. 파일을 **공유 → 링크가 있는 모든 사용자(뷰어)**로 설정합니다.
3. 공유 링크 `https://drive.google.com/file/d/`**`1AbC...xyz`**`/view`에서 굵게 표시한 부분이 파일 ID입니다.
4. 시트 `파일목록` 탭에서 해당 자료 행의 C열에 파일 ID를 붙여 넣습니다. **사이트는 수정할 필요가 없습니다.**

| 파일키 | 파일명 | 드라이브 파일 ID 또는 URL | 사용(Y/N) |
|---|---|---|---|
| manual-a | ISA-W70-6000 운전 매뉴얼 (A형) | 1AbC...xyz | Y |
| manual-b | ISA-W70-6000 운전 매뉴얼 (B형) | *(비어 있음 → 요청 접수)* | Y |

- 새 버전으로 교체할 때도 C열 ID만 바꾸면 됩니다.
- 자료를 잠시 내리려면 D열을 `N`으로 바꿉니다.

> ⚠️ 게이팅할 파일은 저장소 `docs/public/`에 넣지 마세요. 그곳의 파일은 누구나 주소로 바로 받을 수 있습니다.

### 새 자료 추가하기

1. 시트 `파일목록`에 새 행을 추가합니다. 파일키는 영문 소문자와 하이픈으로 정합니다. 예: `manual-c`
2. `docs/download/index.md`의 표에 버튼을 추가합니다.

```html
<a href="#" class="dg-dl" data-gate-file="manual-c" data-gate-label="자료 이름">다운로드</a>
```

## 운영 참고

**시트 컬럼**

- `리드`: 고객 1명당 1행입니다. 같은 이메일로 다시 입력하면 기존 행을 갱신합니다.
- `마케팅 수신 동의(선택)`: 뉴스레터나 영업 연락은 **이 값이 `Y`인 고객에게만** 보내야 합니다.
- `다운로드기록`: 누가, 언제, 어떤 자료를 받았는지 남습니다. 파일이 없어 요청만 접수된 건은 파일명 뒤에 `(파일 미등록·요청 접수)`가 붙습니다.

**개인정보**

- 매일 새벽 3시에 `purgeExpired`가 자동으로 실행됩니다. 마지막 다운로드일로부터 1년이 지난 고객은 `리드`와 `다운로드기록`에서 삭제됩니다. 폼에 안내한 보유 기간과 같습니다.
- 회사 **개인정보처리방침**에 이 수집 항목, 목적, 보유 기간을 반영해야 합니다. 방침 페이지가 생기면 `config.mts`의 `DOWNLOAD_GATE`에 `privacyUrl: '방침 주소'`를 추가하세요. 폼 안내 문구에 링크가 붙습니다.

**보안**

- 숨겨진 `Website` 칸(허니팟)이 채워진 요청은 봇으로 판단해 거절합니다.
- 같은 이메일로 1분에 10회를 넘게 요청하면 막습니다.
- `=`, `+`, `-`, `@`로 시작하는 입력값은 앞에 `'`를 붙여 저장합니다. 시트 수식 주입 방지용입니다.
- 드라이브 링크를 받은 사람이 그 링크를 다른 곳에 공유하는 것까지는 막을 수 없습니다.
