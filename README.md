🛠️ Cold Isostatic Press (CIP) 자가 점검 및 조치 가이드

본 문서는 일신오토클레이브의 Cold Isostatic Press(냉간 등방압 가압장치) 운영 중 발생할 수 있는 일반적인 문제에 대한 자가 진단 및 초기 조치 방법을 안내합니다. 

A/S 서비스를 요청하시기 전에 아래의 항목들을 먼저 확인해 주시면, 보다 빠르고 정확한 문제 해결이 가능합니다.

---

## ⚠️ 안전 주의사항 (필독)
- **절대 임의 분해 금지:** 고압이 형성되는 챔버 및 배관 계통을 임의로 분해하거나 개조하지 마십시오.
- **압력 배출 확인:** 점검 전 반드시 챔버 내부의 압력이 '0'인지 게이지를 통해 확인하십시오.
- **전원 차단:** 전기적인 점검이 필요한 경우 메인 전원을 완전히 차단한 후 진행하십시오.

---

## 🔍 증상별 자가 진단 및 조치 방법

### 1. 전원이 켜지지 않거나 화면이 들어오지 않을 때
- **체크리스트:**
  - [ ] 메인 전원 케이블이 정상적으로 연결되어 있나요?
  - [ ] 장비 후면(또는 측면)의 메인 차단기(NFB)가 'ON' 상태인가요?
  - [ ] 비상정지(E.M.G STOP) 버튼이 눌려 있지 않은지 확인해 주세요. (눌려 있다면 오른쪽으로 돌려서 해제)

### 2. 가압(Pressure)이 전혀 올라가지 않을 때
- **체크리스트:**
  - [ ] 구동용 압축 공기(Air)가 정상적으로 공급되고 있나요? (공기압 게이지 확인)
  - [ ] 벤트 밸브(Vent Valve) 등 수동 밸브가 완전히 닫혀 있나요?
  - [ ] 작동유(작동 유체) 탱크의 수위가 하한선(Min) 이하로 떨어지지 않았나요?

### 3. 설정 압력 도달 후 압력이 점진적으로 떨어질 때 (Leak 현상)
- **체크리스트:**
  - [ ] 고압 배관 연결부나 밸브 주변에서 유체가 미세하게 새어 나오는 곳이 있나요?
  - [ ] 챔버 플러그(상부 덮개)의 O-Ring 체결부 주변에 이물질이 끼어 있지 않나요?
  - **조치:** 누설 부위가 확인되면 즉시 가동을 멈추고 압력을 완전히 뺀 후 A/S를 접수해 주세요.

### 4. 터치스크린에 에러 코드가 뜰 때
- **체크리스트:**
  - 화면에 표시된 에러 코드(예: `ERR-01`, `Over Pressure` 등)를 사진으로 촬영해 주세요.
  - 장비 전원을 껐다가 약 1분 뒤 다시 켜서(재부팅) 에러가 일시적인 통신 오류인지 확인해 보세요.
